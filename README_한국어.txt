Visual Studio에서 HandyHwanseEditor.csproj를 열어 빌드하세요.
메뉴에 장비 데이터 연구 (HEX)가 추가됩니다.
현재는 장비별 획득 체크박스가 아닙니다. 장비 보유 비트와 아이템 ID가 확인되지 않아 임의 활성화 기능을 넣지 않았습니다.
HEX 변경 시 원본 파일의 .equipment-backup 백업을 만듭니다.
실행 파일 빌드는 이 환경에서 Windows .NET Framework 컴파일러가 없어 검증하지 못했습니다.

추가: 장비 후보 비트 체크박스 메뉴. 0x0310~0x0337 영역의 각 비트를 선택 가능. 장비별 코드가 확인되지 않아 장비 이름별 체크박스나 실제 획득 기능이 아님. 변경 전 백업 생성, 저장은 다른 이름으로 저장 이용.
