GitHub 웹 빌드 방법
1. GitHub 새 저장소 생성 (Private 가능)
2. 이 ZIP의 내부 파일/폴더를 저장소 최상위에 업로드 (.github/workflows/build.yml 포함)
3. Actions 탭에서 Build Windows EXE 선택, Run workflow 클릭
4. 성공 후 해당 실행 기록 아래 Artifacts에서 HandyHwanseEditor-Checkbox-Windows 다운로드
주의: 빌드 성공 및 실행 기능은 아직 검증되지 않았습니다. 체크박스는 장비 이름별 선택이 아니라 실험용 비트 편집 기능입니다.
